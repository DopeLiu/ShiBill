# 拾账 ShiBill

一款**纯本地**的 Android 记账 App：它监听微信、支付宝等 App 的支付通知，自动把「你花了多少钱」变成一条待确认的账单。不需要手动一笔笔记，也不用注册账号、不用联网。

> 作者：[@DopeLiu](https://github.com/DopeLiu) ｜ 项目主页：<https://github.com/DopeLiu/ShiBill>

---

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| **通知自动记账** | 微信 / 支付宝 / 云闪付付款后，App 读取那条支付通知，解析出金额与方向（支出 / 收入），弹出一条通知或提示条，点一下即可入账。 |
| **自动入账（可选）** | 在规则页打开「自动入账（免确认）」后，解析成功的账单直接入库，不再需要确认。 |
| **手动记账** | 首页右下角 `+`，或从通知里点「手动补记」，随时补一笔。 |
| **账单导入** | 支持导入**支付宝官方导出的 CSV** 和**微信官方导出的 xlsx** 账单，自动去重、自动分类。 |
| **统计** | 按月查看支出 / 收入合计、分类排行、近 6 个月趋势。 |
| **分类关键词** | 每个分类可以配置关键词（如「美团、饿了么」），命中的账单自动归入该分类。 |
| **自定义解析规则** | 内置微信 / 支付宝规则可停用、可编辑；也能自己新建规则，扩展到任意 App（如银行 App）。 |
| **备份与导出** | JSON 全量备份（可导入还原）、CSV 账单导出（GBK 编码，Excel 可直接打开）。 |
| **检查更新** | 仅在手动点击时访问 GitHub Releases，是 App 唯一的联网行为。 |

## 怎么用

1. **安装**：从 GitHub Releases 下载 APK 安装（或自行编译，见文末）。
2. **首次启动**：跟着 2 步引导走完。
   - 第 1 步：了解 App 做什么。
   - 第 2 步：**开启「通知使用权」**——这是自动记账的核心权限，点「去开启通知使用权」跳到系统设置，找到「拾账」并打开。若系统弹出「发送通知」权限请求，请一并允许，否则收不到记账提醒。
3. **正常支付**：用微信 / 支付宝付款后，App 会捕获通知并弹出一条「记一笔：¥25.00（微信）」，点击即可确认入账。
4. **下拉通知栏**：所有提醒都走同一个通知渠道「记账确认」。若杀掉了 App，重新打开即可（不保留历史待确认记录）。

### 国产手机的必要设置

为保证通知监听在后台稳定收到消息，建议在「应用管理 / 电池设置」中：

- 电池策略设为「无限制 / 不优化」
- 打开「自启动 / 后台自启动」
- 在最近任务列表中锁定拾账（部分系统：下拉卡片点锁图标）

## 隐私说明

- **数据只存在你的手机本地**，无账号、无云同步、无上传。
- **通知监听只读取通知的标题和正文文本**，用于解析金额，不会保存聊天内容；解析过程产生的临时原始记录保留 7 天后自动删除。
- **唯一的联网行为**是在你主动点击「检查更新」时访问 GitHub Releases。除此之外不发起任何网络请求。
- 导出的备份 / 账单文件由你自己保存与分享，App 不会主动外传。

## 目前的使用边界

- **只对「已配置」的 App 生效**。默认只监控微信、支付宝（含渠道包）、云闪付，且内置解析规则只覆盖微信和支付宝。其余 App（包括银行 App）默认不会被记账——需要你在规则页添加包名并新建规则。
- **支付宝部分通知形态可能识别不了**。例如正文不带「支付宝」字样、开头又不是锚点词的形态，会走到「疑似支付，手动补记」提示（属已知缺口）。
- **自动捕获的账单没有商户名**（通知里通常就没有），因此列表里可能显示为分类名或「未分类」，分类也需要靠关键词或手动调整。
- **极少数情况下可能漏记或误合并**：同一分钟内、同一 App、金额完全相同的两笔真实交易，可能被判定为同一笔而只入账一次。

## 自行编译

需要 Android SDK（API 35）与 JDK 17 或更高。

```bash
# Windows / macOS / Linux 通用
./gradlew :app:assembleDebug      # 产物：app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest  # 运行单元测试
```

> 若本机未设置 `JAVA_HOME`，Gradle 会直接报错。可以指向 Android Studio 自带的 JDK，例如：
> `export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"`（Git Bash 语法）。
>
> 更详细的构建、架构与维护说明见 [DEV_NOTE.md](DEV_NOTE.md)。

发布正式包时，在仓库根目录放 `keystore.properties`（不入库）即可自动签名；CI 通过标签触发，见 `.github/workflows/release.yml`。
